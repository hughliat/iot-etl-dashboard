## 3. 构建与发版步骤

```bash
python -m pip install -r requirements.txt
make run          # 或 python -m src.cli run --scale default
make test         # 或 python -m pytest -q
```

发版方式：GitHub 仓库打 tag `v1.0.0` 并发布 Release；产物不入库（`output/`、`data/` 已 gitignore），仅提交源码与文档。

## 4. 产物位置与校验

产物由 `make run` 生成，位于项目根 `output/`：

| 产物 | 说明 |
|---|---|
| `output/iot_etl.db` | SQLite 库，7 张表 |
| `output/dashboard.html` | 静态看板（内嵌 SVG，无 CDN） |
| `output/dashboard_data.json` | 看板数据 |
| `output/data_quality_report.json` | 数据质量报告 |
| `output/sql_optimization_report.json` | SQL 优化对比结果 |

校验方式：default 规模连跑两次，`data_quality_report.json` 与 `dashboard_data.json` 两次 `diff` 完全一致（确定性）。

## 5. 部署记录

本项目为离线个人展示项目，无服务端部署、无进程/端口/监控项。部署等价于在全新环境执行 `make run` 生成产物。已在 Windows（Python 3.13.14，Git Bash）验证通过；Makefile 目标在 Linux/macOS 尚未实测（见 §8）。

## 6. 验证结果

引自 `docs/04-测试报告.md`（结论：通过）：

- 单元测试 14/14 通过（0.11s）。
- 全链路 default 退出码 0，产物齐全。
- SQL 优化（stress，约 432 万行）：baseline 1.9076s → optimized 0.3443s，提速约 5.54x，EXPLAIN 呈现 SCAN→SEARCH。
- 数据质量：651,318 → 648,000（去重 3,318、越界 1,975、缺失 1,939）。
- 确定性复现：default 连跑两次产物 diff 一致。

## 7. 回滚方案

```bash
# 回退代码：删除 tag 并回到上一提交
git tag -d v1.0.0
git checkout <previous-commit>

# 清理本地生成的中间产物
make clean          # 等价 rm -rf output data
```

回滚后验证：重新 `make run` 产出即视为回退成功。本项目无持久化服务，无数据风险。
