### 4.3 SQL 优化对比（stress 规模，约 432 万行）

`python -m src.cli benchmark --scale stress` → 退出码 **0**，耗时 2m57.8s。

- baseline EXPLAIN：`SCAN dwd_sensor_clean`
- optimized EXPLAIN：`SEARCH dwd_sensor_clean USING INDEX idx_dwd_site_ts (site_id=? AND ts>?)`
- 计时均值：baseline 1.9076s / optimized 0.3443s，**提速约 5.54x**
- 结果落盘 `output/sql_optimization_report.json`。

（注：提速比随机器负载波动，本次 default 规模另测得约 2.72x；SCAN→SEARCH 结构变化稳定成立。）
